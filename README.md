# super Luigi

A 2D platformer built with **Godot 4.6** + **Jolt Physics**.

> Work in progress — the project is being actively developed. Expect rough edges.

## Tech

- Engine: Godot 4.6 (`mobile` rendering backend, D3D12 on Windows)
- Physics: Jolt
- Language: GDScript

## Getting started

1. Install [Godot 4.6](https://godotengine.org/) (standard or .NET build).
2. Clone this repo.
3. Open `project.godot` in the Godot editor.
4. Press **F5** (or click the play button) to run `main.tscn`.

## Project layout

```
.
├── addons/                 # Third-party editor plugins
│   └── godot_super-wakatime/   # hackatime / wakatime integration
├── main.tscn               # Entry-point scene
├── project.godot           # Godot project configuration
└── icon.svg                # Default project icon
```
